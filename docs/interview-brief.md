# 面试复盘：澳门低空医疗急送

数字来自本机这一次 `scripts/perceive.py` 和 `scripts/learn_cost.py`。三关仍是路环、半岛、离岛（机场净空加城市峡谷）。

## 30 秒

这是澳门低空医疗急送的三关规划。禁飞是硬约束，用顶点可视图加 Dijkstra 求最短路；综合代价是航程米数加飞行秒数乘 12，限高段 7 m/s，区外 12 m/s，再扣逆风。感知层用 YOLO11n 读 9 张公开照片，把 45 个检测框收成拍摄点风险。航段代价用梯度提升树来学，预测值当有向边权，走出第二条路。离岛这一关，学习代价路多飞 88 米，少穿 255 米限高，综合代价低 328。

## 演示顺序

1. 打开页面，先读顶栏：禁飞、限高、电磁和人口都是教学演示，不是澳门法定管制空域，也不能当飞行批准。
2. 在任务页选「离岛转运 · 净空与峡谷」。这一关同时有跑道净空、油库和城市峡谷。
3. 侧栏图层保持禁飞、限高、人口、风、检测风险、对比航线都打开。红区是禁飞，橙区是限高，人口是 2021 普查，箭头是这一关的均匀风，品红点是照片风险。
4. 看两条参考线。灰虚线只最小化距离，8.14 km，综合代价 19,129，限高段 810 米。橙色实线是学习代价路，8.23 km，综合代价 18,801，限高段 555 米。两条线最远处大约相距 455 米。
5. 读侧栏里的模型卡。6393 条教学边，留出 1279 条。梯度提升树 MAE 59.13，R² 0.9982，Spearman 0.9975。线性回归对照 MAE 183.13，R² 0.9801。重要性最高的是航段长度 0.9645。散点图是留出集上的预测对标签。
6. 点「开始规划」。对比航线先收起，避免对着答案画。按顺序把点落进四个配送点的捕获圈，双击或按 Enter 提交。复盘表有三列：你的航线、距离最短、学习代价。
7. 若还要看检测，回到任务页打开「半岛老城」。议事亭前地那张日间照片检出 12 个行人，风险 6.89；距离最短路的检测密度 1.78，学习代价路 1.61。航程多 21 米，综合代价高 50，教学标签低 65。
8. 用下面三句收尾：教学禁飞半径不是法定空域；2021 普查盖不住全部航线；YOLO 不是用澳门航拍训出来的。

## 方法链

| 环节 | 输入 | 输出 | 为什么这样选 |
| --- | --- | --- | --- |
| 底图与任务 | OSM 跑道、医院、卫生站、带高度的建筑；2021 普查分区；三关起降点和配送点 | `data/levels/*.json`、`data/population.json` | 配送点、跑道和密度都能对上公开数据。航线是直线折线，所以不用路网。 |
| 可视图 | 起降点、配送点、禁飞顶点；学习图再加每片限高边界最多 8 个点 | 不穿禁飞内部的边 | 顶点可视图加 Dijkstra 是避障最短路。限高点只是可绕行的顶点，进了限高不算失败。 |
| 航段特征 | 边的长度、与任务直线的夹角、限高比例、人口密度、距禁飞区、风向夹角、检测密度 | 7 维向量 | 边权只能依赖这一边。真实转弯依赖上一条边，普通 Dijkstra 吃不进去，所以转角用本边相对任务直线的夹角。 |
| 教学标签 | 综合代价 + 检测密度 × 80 + 转角 × 0.35 | 一条边一个数 | 综合代价沿用原规则：米数 + 秒数 × 12。80 和 0.35 是教学附加，用来让照片风险和转角进得了边权。 |
| 检测 | 9 张带相机坐标的公开照片 | 45 个框，拍摄点风险和 18.40 | 见下一节。框不投影到地面。风险用 450 米指数核摊到边上。 |
| 代价模型 | 6393 条边，80% 训练、20% 留出，种子 0 | 留出集误差和特征重要性；用训练集拟合的树给边权 | 树能分开「限高里变慢」这种折线。线性回归是对照，留出误差更大，不拿去寻路。 |
| 两条路 | 同一批顶点，两种边权 | 距离最短路、学习代价路 | 差别来自边权。风和转角随方向变，所以图是有向的，两个方向各预测一次。 |
| 界面 | 上述 JSON | Leaflet 上的禁飞、限高、人口、风、检测点和两条线 | 游戏仍按原规则计分。排行榜只看综合代价，不看教学标签。 |

离岛的距离最短路：航程 8141.8 米，飞行 915.6 秒，限高 809.7 米，综合代价 19129.0，检测密度 0.44，长度加权人口密度 7568。学习代价路：航程 8230.1 米，飞行 880.9 秒，限高 555.0 米，综合代价 18801.1，检测密度 0.39，人口密度 29057。多飞 88.2 米，少穿限高 254.7 米，综合代价低 327.9，教学标签低 527。绕开峡谷时飞进了更密的普查分区。人口密度的重要性只有 0.0001，树没有为了躲开人去改道。

路环两条路航程只差 0.04 米（5874.65 对 5874.69），综合代价高 3.7，教学标签低 170，折线最远处相距约 351 米。半岛学习代价路多飞 21.1 米，综合代价高 49.6，教学标签低 65.2，检测密度从 1.781 降到 1.606。

## 专业名词

| 名词 | 在这个项目里指什么 |
| --- | --- |
| 可视图 | 起降点、配送点和禁飞顶点之间，凡是不进入禁飞区内部的直线 |
| Dijkstra | 在这张图上求边权之和最小的折线 |
| 综合代价 | 航程（米）+ 飞行时间（秒）× 12。无风且不进限高时等于航程的 2 倍 |
| 地速 | max(3, 空速 − 逆风分量)。限高内空速 7 m/s，外面 12 m/s |
| 教学标签 | 综合代价 + 检测密度 × 80 + 转角（度）× 0.35。只用于训练和寻路 |
| 检测密度 | 拍摄点风险沿 450 米指数核衰减后，在航段 1/4、1/2、3/4 处的平均 |
| 留出集 | 6393 条边里随机留出的 1279 条，种子 0。指标只在这 1279 条上算 |
| MAE | 留出集上预测和教学标签的平均绝对误差，单位和教学标签一样 |
| R² | 留出集上预测解释了多少标签方差 |
| Spearman | 预测排序和标签排序的一致性。树是 0.9975，线性回归是 0.9906 |
| 特征重要性 | 梯度提升树的分裂重要性。航段长度 0.9645，风向夹角 0.0329 |
| 长度加权人口密度 | 落在 2021 分区里的航段，按长度对密度加权。分区外的长度不参加平均 |

## 三个追问

**为什么 R² 有 0.998，检测和限高的重要性却几乎是 0？第三关又为什么少穿了峡谷？**

标签大致跟着航程走，无风且不进限高时综合代价正好是航程的 2 倍，所以长度拿走 0.9645 的重要性。限高只把落在峡谷里的那一段从 12 m/s 改成 7 m/s，检测附加是密度乘 80 米，相对整条边的长度都很小，重要性分别是 0.0010 和 0.0012。树仍然能在这些边上把限高段预测得更贵。离岛学习代价路的限高段是 555.0 米，距离最短路是 809.7 米，所以综合代价从 19129.0 降到 18801.1。人口密度重要性是 0.0001，这条绕行的长度加权密度从 7568 升到 29057，模型没有为了少飞过人去改道。

**照片里的人和车，怎么变成地图上的代价？**

每张照片先在像素里检测。议事亭前地 `Largo do Senado 1110301.jpg` 的 12 个框全是人，置信度从 0.8205 到 0.2676，风险 6.8898。威尼斯人东大堂有 8 个人和一个时钟，时钟不在风险类里，风险 4.4681。另一张议事亭夜景只检出一盆盆栽，风险 0。路环面店检出碗和餐桌，风险也是 0。风险乘类别权重后放在文件页的相机坐标上，再按 450 米指数核加到航段上。框没有铺到地面。室内大堂也不是低空航拍，它只说明这张照片的拍摄点附近有人。

**这套空域能拿去报飞吗？**

不能。禁飞圆的半径是为了挡住任务直线而设的教学半径，跑道是 OSM 中心线外扩约 430 米，都不是法定空域，也不是障碍物限制面。2021 普查分区盖不住全部路环南岸和新填海，路环距离最短路有约 4.45 km 落在分区外，脚本不会把这段空白当成低密度。YOLO11n 是 COCO 预训练，不是用澳门航拍训的，类别也不是低空障碍物。

## 局限

- 教学禁飞半径不是澳门法定管制空域，不能当作飞行批准。
- 2021 人口普查分区有覆盖缺口，路环和九澳都有一段航线落在分区外面。
- YOLO 不是用澳门航拍训出来的。权重是 COCO 的 YOLO11n，照片是地面或室内公开图片，检测框留在像素坐标里。
